# Empty Registry Statement

As of 30 July 2026, the GeoProspect model registry is intentionally empty.

Stage 0 evaluates whether a scientifically defensible mineral-prospectivity experiment is possible. It does not authorise model training, model publication, prospectivity scoring or predictive-performance claims.

No model file, checkpoint, serialized estimator, embedding, prospectivity raster, ranked target or benchmark result belongs in this repository until a later-stage release is explicitly authorised through the central GeoProspect governance repository.
