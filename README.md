# GeoProspect Models

Model registry and model-card repository for the GeoProspect project.

## Current status

**EMPTY REGISTRY — Stage 0 active and Stage 1 blocked.**

No trained model, checkpoint, weight file, prospectivity score, benchmark result or claimed predictive-performance result is authorised during Stage 0.

## Permitted Stage 0 contents

- This repository responsibility statement.
- An empty-registry statement.
- A model-card template.
- A future model-release policy.

## Prohibited Stage 0 contents

- Trained model files or checkpoints.
- Serialized estimators, embeddings or feature stores.
- Prospectivity rasters, ranked targets or scores.
- Performance claims or benchmark tables.
- API or deployment artefacts.

A model may be published only after the central repository records an authorised later-stage release that satisfies the release policy and preserves the limitations established by the Stage 0 evidence package.

Central governance and code: [`Lukeyone/geoprospect`](https://github.com/Lukeyone/geoprospect)  
Approved public data products: [`Lukeyone/geoprospect-data`](https://github.com/Lukeyone/geoprospect-data)
